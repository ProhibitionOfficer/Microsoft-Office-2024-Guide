## 📌 What is Microsoft Office 2024?

Microsoft Office 2024 is the **latest perpetual-license version** of Microsoft's core productivity apps — purchased once rather than subscribed to. It includes Word, Excel, PowerPoint, and (on Windows) Outlook, but unlike Microsoft 365, it does not include cloud services like Teams, ongoing feature updates, or ongoing Copilot AI access.

## ✨ Key Features

| Feature                     | Description                                                    |
| ------------------------------- | ---------------------------------------------------------- |
| Word, Excel, PowerPoint          | Core document, spreadsheet, and presentation apps                  |
| Outlook (Windows only)             | Email and calendar client, not included in the Mac edition          |
| One-time Purchase                   | No recurring subscription fee for the life of this version           |
| Security & Bug Fix Updates            | Ongoing security patches for the version's supported lifecycle         |
| Offline-first Use                      | Works fully installed on one device with no subscription check          |
| Limited AI Features                     | Basic AI tools included; Microsoft Copilot requires a separate subscription |
